# 欢迎使用 MkDocs Material

本站点由飞牛 fnOS 应用「MkDocs Material」部署，已预置最小可用站点，可直接开始写作。

## 开始使用

1. 打开应用数据目录（安装时选择的存储空间下的应用数据），进入 `data/`。
2. 在 `docs/` 中新增或编辑 Markdown 文件。
3. 修改 `mkdocs.yml` 的 `nav` 调整导航结构。
4. 保存后刷新页面即可看到更新。

## 说明

- `mkdocs.yml` 是站点配置，缺失时容器无法启动，本应用已随包提供一份可用的初始配置。
- 首次安装只会写入初始版本，之后不会覆盖你修改的内容。
