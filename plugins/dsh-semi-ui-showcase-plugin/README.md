# @tnnevol/dsh-semi-ui-showcase

`@tnnevol/dsh-semi-ui` 的组件总览插件。集中检查共享的 Semi Design 组件和主题状态，自己不维护第二套样式。

## 安装

插件发布在 npm，要求 DSH `0.1.5-rc.2` 。安装命令：

```sh
dsh plugin --profile web add @tnnevol/dsh-semi-ui-showcase@0.1.5-rc.2
```

装完重启 Web profile 即可。

## 功能

- 在任意会话头部右侧点 `Semi UI` 文本按钮，进入组件总览页
- 覆盖按钮、图标、下拉、级联、树、弹窗、进度、加载和提示等组件
- 检查浅色、深色和系统三种主题下的组件状态和浮层表现

更完整的说明见线上文档：<https://fnapps-doc.tnnevol.cn/plugins/dsh-semi-ui-showcase>
