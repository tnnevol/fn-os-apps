# NVM

## 应用简介

NVM 是 Node.js 版本管理工具，提供 `nvm` 命令用于安装和切换不同版本的 Node.js。

## 主要能力

- 安装多个 Node.js 版本。
- 在不同版本之间切换。
- 为其他应用或命令行任务提供可选的 Node.js 运行时。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-nvm` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装后在应用提供的用户环境中使用 `nvm`。切换版本前确认目标应用的 Node.js 兼容性，并避免修改系统级 Node.js 路径。
