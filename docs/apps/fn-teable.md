# Teable

## 应用简介

Teable 是基于 PostgreSQL 的智能表格平台，把数据库变成类 Airtable 的协作界面。

## 主要能力

- 把数据库表转为智能表格。
- 多种视图（表格、看板、画廊等）。
- 团队协作与 API 接入。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-teable` |
| 目标平台 | x86 |
| 外部依赖 | **外部 PostgreSQL + Redis** |

## 安装与使用

安装时设置 Web 访问端口与容器时区，填写**站点访问地址**、数据库连接信息（地址、端口、库名、用户名、密码分开填写）与 **Redis 地址/端口/密码**。

**数据库需用户自备**：安装时填写数据库连接信息。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**本应用同时依赖 PostgreSQL 与 Redis**：PostgreSQL 保存表格数据，Redis 用于缓存。**Redis 连接失败时应用仍会启动，但缓存与会话功能异常。** 安装时会自动安装飞牛应用中心的 Redis 依赖。

**已修正的上游缺陷**：上游把数据库端口（5432）与 Redis 端口（6379）都**写死在连接串里**，会把你锁死在默认端口；已改为向导字段。

**站点访问地址**上游默认是占位符 `<YOUR IP>`，已改为必填。

**运行身份**：本应用以目标 NAS 的包用户（非 root）运行。数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。

## 高级配置

### 数据库类型

上游向导声明了数据库类型字段（仅 `postgresql`），但容器编排把 `postgresql://` 前缀**直接写在连接串里**、并未引用该字段，因此**不提供类型选项**。
