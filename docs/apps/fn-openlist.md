# OpenList

## 应用简介

OpenList 是多存储文件列表程序，把多个网盘与本地存储聚合为一个统一入口。

## 主要能力

- 聚合多种网盘与本地存储。
- Web 界面浏览、上传、下载与分享。
- 提供 WebDAV 与 S3 兼容接口。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-openlist` |
| 目标平台 | x86 |
| 外部依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口、S3 API 端口与时区，安装完成后从应用中心打开并按提示创建管理员账号。

**两个端口的区别**：Web 访问端口是网页界面（已创建桌面入口）；S3 API 端口提供 S3 兼容接口，**供其他程序调用，不是给人浏览的页面**，因此没有桌面入口。

数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。

**运行身份**：上游显式要求以 root（`user: "0:0"`）运行，而本应用镜像本身设计为非 root 的专用用户。转换后改为以 fnOS 为应用分配的用户运行，**属恢复镜像本意**。

> **关于上游的「预装环境」选项**：上游提供 ffmpeg（缩略图）/ aria2（离线下载）等变体，其镜像名由上游的初始化脚本拼接生成，在本平台没有对应的执行时机，**因此本转换未提供该选项**，统一使用标准镜像。

## 端口说明

| 端口 | 用途 | 桌面入口 |
| --- | --- | --- |
| Web 访问端口（默认 5244） | 网页界面 | ✅ 有 |
| S3 API 端口（默认 5246） | S3 兼容接口，供程序调用 | — 无 |

S3 端口用于把 OpenList 当作对象存储后端给其他程序使用（例如备份工具）。若不需要可以不对外暴露。
