# Umami

## 应用简介

Umami 是注重隐私的网站统计分析工具，提供访客、来源与页面数据看板。

## 主要能力

- 隐私友好的访问统计，不采集个人数据。
- 多站点管理与共享链接。
- 访问来源、页面与事件分析。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-umami` |
| 目标平台 | x86 |
| 外部依赖 | **外部 PostgreSQL 数据库** |

## 安装与使用

安装时设置 Web 访问端口，并填写**应用密钥**与数据库连接信息。

数据库需用户自备：安装时填写**数据库连接**（格式「地址:端口/数据库名」）、数据库名、用户名与密码。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

本应用使用 **PostgreSQL**（上游 `PANEL_DB_TYPE` 默认值即 postgresql）。**存储说明**：本应用不落盘任何数据，全部数据保存在你所提供的 PostgreSQL 实例中——**卸载时请自行处理数据库中的数据**，本应用的「保留数据」选项对数据库内容无效。
