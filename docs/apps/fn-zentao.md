# 禅道

## 应用简介

禅道是国产开源项目管理平台，覆盖产品、项目、质量、文档、办公和资产管理等场景。

## 主要能力

- 产品与项目管理。
- 敏捷和 Scrum 协作。
- 质量、文档、办公和资产管理。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-zentao` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装后进入初始化页面，创建管理员账号并根据团队规模配置项目、用户和权限。升级前建议备份应用数据。
