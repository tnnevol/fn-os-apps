# 小雅

## 应用简介

小雅是基于 Alist 的网盘聚合工具，适合在 fnOS 上统一管理多个云存储并提供媒体访问能力。

::: warning 数据目录
当前暂未适配数据目录生成脚本。如果需要使用相关功能，请先将数据迁移到应用安装的数据目录：

`${TRIM_APPDEST_VOL}/@appshare/fn-xiaoya-only/alist/data/`

例如应用安装在存储 4，实际目录为 `/vol4/@appshare/fn-xiaoya-only/alist/data/`。
:::

## 主要能力

- 聚合多种网盘存储。
- 支持在线播放和 WebDAV。
- 提供目录索引和文件管理能力。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-xiaoya-only` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装后通过 fnOS 桌面入口打开应用，并按照应用页面完成网盘或媒体目录配置。数据目录和权限以安装向导及应用设置为准。
