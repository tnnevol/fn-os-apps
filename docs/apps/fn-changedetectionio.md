# Changedetection.io

## 应用简介

Changedetection.io 是开源的网页变更检测与通知服务，可监控页面内容变化、补货信息等。

## 主要能力

- 按计划监控网页内容变化。
- 支持视觉选择器与 CSS/XPath 精确定位。
- 变更时通过多种渠道发送通知。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-changedetectionio` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开，添加要监控的网址并设置检查间隔与通知方式。监控目标与历史快照保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
