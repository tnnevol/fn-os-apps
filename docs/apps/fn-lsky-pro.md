# 兰空图床（Lsky Pro）

## 应用简介

兰空图床（Lsky Pro）是自托管的图片托管与图床系统，支持多种存储策略。

## 主要能力

- 图片上传、管理与外链。
- 多种存储策略（本地、对象存储等）。
- 用户与相册管理。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-lsky-pro` |
| 目标平台 | x86 |
| 外部依赖 | 无（数据库在**首次访问时由应用自行引导配置**） |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开，**按页面上的安装向导填写数据库等配置**。

**本应用不含数据库配置项**：它的数据库连接在**首次访问的 Web 安装向导**中填写登录，因此向导不提供数据库字段。

**端口说明**：上游把容器内监听端口固定为 8089，宿主映射为 `${APP_PORT}:8089`。你修改访问端口时**只影响宿主侧**，容器内始终监听 8089，映射关系一致，因此可正常工作。

**运行身份**：本应用以目标 NAS 的包用户（非 root）运行。

> **真机验证项**：本镜像为 Apache 系，**以非 root 运行时的 pid/日志目录写入行为尚未在真机确认**；若出现启动异常，可临时在编排中移除 `user:` 行以 root 运行并回报问题。

数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。
