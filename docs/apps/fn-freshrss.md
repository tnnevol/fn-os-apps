# FreshRSS

## 应用简介

FreshRSS 是自托管的 RSS 和 Atom 源聚合器，支持多用户与全文抓取。

## 主要能力

- 订阅并聚合 RSS/Atom 源。
- 多用户支持与阅读进度同步。
- 可选的全文抓取与过滤规则。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-freshrss` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口与容器时区，安装完成后从应用中心打开并完成初始化。订阅源、文章与配置保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
