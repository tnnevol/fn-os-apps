# Kirara Agent

## 应用简介

Kirara Agent Framework 提供可编排的 AI 智能体运行时，用于搭建多步推理与工具调用流程。

## 主要能力

- 编排多步智能体推理流程。
- 支持接入多种大模型与工具。
- 提供 Web 界面进行配置与观察。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-kirara-agent` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开进行配置。数据保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
