# 签到框架

## 应用简介

自动签到框架，支持编写与定时执行各类站点的签到任务，并汇总执行结果。

## 主要能力

- 编写并定时执行签到任务。
- 支持多种站点模板与登录方式。
- 任务日志与失败重试。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-qiandao` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，并填写 **AES 加密密钥**与 **Cookie 加密密钥**（上游默认值是弱占位符，请各自设置为唯一的强口令）。安装完成后从应用中心打开，首个注册用户即为管理员。任务配置与数据库保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
