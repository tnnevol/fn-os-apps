# Web-Check

## 应用简介

Web-Check 是用于分析网站的多合一 OSINT 工具，把域名、DNS、证书、头部与威胁情报等信息汇总在一页。

## 主要能力

- 域名与 IP 信息、DNS 记录与解析链路。
- SSL 证书、HTTP 头部与重定向分析。
- 开放端口、爬虫规则、站点技术栈识别。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-web-check` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开，输入要分析的网址即可生成报告。请仅对自己有权检测的站点使用。
