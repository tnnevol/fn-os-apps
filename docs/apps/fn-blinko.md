# Blinko

## 应用简介

Blinko 是注重隐私的快速笔记工具，支持 AI 增强检索与标签整理。

## 主要能力

- 快速记录想法与待办。
- AI 增强的语义检索。
- 标签与时间线整理。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-blinko` |
| 目标平台 | x86 |
| 外部依赖 | **外部 PostgreSQL 数据库** |

## 安装与使用

安装时设置 Web 访问端口，填写**站点访问地址**（如 http://192.168.1.10:1111，**填错会导致登录回调失败**）、**会话密钥**，以及数据库连接信息。

**数据库需用户自备**：安装时填写数据库连接信息。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**注意**：本应用使用 **PostgreSQL**。数据保存在你所提供的数据库中，应用数据目录只保存上传的附件与缓存。数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。
