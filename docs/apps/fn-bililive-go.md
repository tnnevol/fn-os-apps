# Bililive-go

## 应用简介

Bililive-go 支持多个直播平台的自动录制，可按房间配置持续保存直播内容。

## 主要能力

- 支持多个主流直播平台的录制。
- 按房间配置录制规则与画质。
- 提供 Web 界面查看录制状态。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-bililive-go` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开，添加要录制的直播间即可。录制配置与录像文件保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复；**录像文件会持续增长，请注意存储容量**。
