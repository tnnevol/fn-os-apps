# DBHub

## 应用简介

DBHub 是数据库通用网关，为多种数据库提供统一的连接与访问入口。

## 主要能力

- 为多种数据库提供统一访问入口。
- 便于与其它工具或 AI 客户端集成。
- 无需为每种数据库单独接入。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-dbhub` |
| 目标平台 | x86 |
| 外部依赖 | **外部数据库** |

## 安装与使用

安装时设置 Web 访问端口，并填写**数据库连接**（格式「地址:端口/数据库名」）、用户名与密码。

数据库需用户自备：安装时填写**数据库连接**（格式「地址:端口/数据库名」）、数据库名、用户名与密码。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**存储说明**：本应用不落盘，数据保存在你所提供的数据库中。
