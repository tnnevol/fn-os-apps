# CyberChef

## 应用简介

CyberChef 是运行在浏览器中的数据处理工具，可在不安装任何软件的情况下完成编码、解码与数据分析。

## 主要能力

- 编码与解码：Base64、URL、十六进制、字符集转换等。
- 数据格式转换：JSON、CSV、时间戳、进制转换等。
- 加密与哈希：常见对称加密、摘要算法与校验和。
- 全部计算在浏览器本地完成，数据不上传。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-cyberchef` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开即可使用，所有操作在浏览器本地执行。
