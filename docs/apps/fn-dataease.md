# DataEase

## 应用简介

DataEase 是开源的数据可视化分析平台，拖拽式制作图表与仪表板。

## 主要能力

- 拖拽式制作图表与仪表板。
- 支持多种数据源接入。
- 提供分享与导出。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-dataease` |
| 目标平台 | x86 |
| 外部依赖 | **外部 MySQL 数据库** |

## 安装与使用

安装时设置 Web 访问端口，填写**管理员账号与密码**（上游默认密码是弱占位符，请自行填写）以及数据库连接信息。

数据库需用户自备：安装时分别填写**数据库地址、端口、库名、用户名与密码**。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**存储说明**：配置、日志、缓存与各类资源共 7 个目录保存在应用数据目录中；**业务数据本身保存在你所提供的 MySQL 实例中**，卸载时请自行处理。

## 高级配置

### 关于版本

上游同时提供 `v2.10.27` 与 `v3.1.0` 两个版本。本应用按项目清单登记取 **v2.10.27**，其容器内路径为 `/opt/dataease2.0/...`（3.x 版本是 `dataease3.0`）。**升级到 3.x 需重新转换并处理数据迁移**，不要在现有安装上直接替换镜像。
