# DataEase

## 应用简介

DataEase 是开源的数据可视化分析平台，拖拽式制作图表与仪表板。

## 主要能力

- 拖拽式制作图表与仪表板。
- 支持多种数据源接入。
- 提供分享与导出。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-dataease` |
| 目标平台 | x86 |
| 外部依赖 | **外部 MySQL 数据库** |

## 安装与使用

安装时设置 Web 访问端口，填写**管理员账号与密码**（上游默认密码是弱占位符，请自行填写）以及数据库连接信息。

数据库需用户自备：安装时分别填写**数据库地址、端口、库名、用户名与密码**。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**数据源配置随包提供（3.1.0 起必须）**：镜像自身不读 `PANEL_DB_*`，它把数据源交给外置的 `conf/application.yml`（挂载到容器内 `/opt/apps/config/`）。本应用随包提供一份**自写的最小可用配置**（`app/seed/conf/application.yml`），由 `cmd/install_callback` 在文件缺失时铺入；文件已存在则**不覆盖**，用户改过的配置在重装或升级后保留。缺少该文件时的表现是容器**重启循环**、入口完全不可访问（真机复现：Spring 回退到 `localhost:3306` 报 `Connection refused`），而不是「能启动但功能受限」。

**存储说明**：配置、日志、缓存与各类资源共 13 个目录保存在应用数据目录中；**业务数据本身保存在你所提供的 MySQL 实例中**，卸载时请自行处理。新增的 `map`、`appearance`、`plugin`、`driver`、`i18n`、`report` 六个目录由安装回调预创建，容器以包用户运行时才有写权限。

## 高级配置

### 关于版本

本应用现同步到上游最高的 **v3.1.0**。上游同时保留 `v2.10.27`，两个大版本的**容器内数据路径不同**：2.x 用 `/opt/dataease2.0/...`，3.x 用 `/opt/dataease3.0/...`，且 3.x 多了六个用途目录。本次已按 3.x 编排更新挂载目标与目录预创建逻辑，宿主侧数据目录名未变，因此原有文件不会丢失。

上游将本应用标记为 `crossVersionUpdate: false`（不支持跨版本升级）。**已经安装过 2.x 的设备升级到本版本前，请先备份 MySQL 数据库并确认 3.x 的数据库结构迁移方案**；这是数据兼容性问题，不是挂载路径问题。
