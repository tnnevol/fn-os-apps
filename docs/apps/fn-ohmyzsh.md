# Oh My Zsh

## 应用简介

Oh My Zsh 是开源、社区驱动的 Zsh 配置管理框架，通过插件和主题增强命令行体验。

## 主要能力

- 提供丰富的 Zsh 插件。
- 支持主题和命令提示符配置。
- 统一管理用户的 Zsh 配置文件。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-ohmyzsh` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装后按照应用说明配置用户环境。`.zshrc` 位于应用文件目录中，修改前建议备份现有 Shell 配置。
