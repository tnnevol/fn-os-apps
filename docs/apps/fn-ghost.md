# Ghost

## 应用简介

Ghost 是专注写作与出版的现代博客平台，内置会员与订阅功能。

## 主要能力

- 专注写作的编辑器。
- 内置会员与订阅。
- 主题与内容 API。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-ghost` |
| 目标平台 | x86 |
| 外部依赖 | **外部 MySQL / MariaDB 数据库** |

## 安装与使用

安装时设置 Web 访问端口，填写**站点访问地址**（如 http://192.168.1.10:2368，**填错会导致后台登录跳转异常与文章链接错误**）以及数据库连接信息（地址、端口、库名、用户名、密码分开填写）。

**数据库需用户自备**：安装时填写数据库连接信息。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**端口说明**：上游编排未提供数据库端口配置（隐含 3306）。fnOS 上数据库由你自备、端口不一定是 3306，**故本应用补出了数据库端口字段**。

数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。
