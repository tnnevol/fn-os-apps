# ShowDoc

## 应用简介

ShowDoc 是在线文档与 API 文档管理工具，适合团队维护接口文档与内部知识库。

## 主要能力

- Markdown 编写与目录管理。
- API 文档与在线调试。
- 团队协作与权限控制。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-showdoc` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开并完成初始化。文档数据与上传附件保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
