# Memos

## 应用简介

Memos 是轻量级自托管笔记工具，适合在 NAS 上记录和管理个人或团队知识。

## 主要能力

- 使用 Markdown 编写笔记。
- 使用标签组织内容。
- 支持多端同步和自托管部署。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-memos` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装后从桌面入口打开应用，完成首个用户和访问权限配置。重要数据建议结合 fnOS 备份策略定期备份。
