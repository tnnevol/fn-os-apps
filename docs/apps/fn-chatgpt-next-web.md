# ChatGPT-Next-Web

## 应用简介

ChatGPT-Next-Web 是可直接自托管的聊天界面，支持自定义 API 地址与访问密码，适配多种兼容 OpenAI 的服务。

## 主要能力

- 接入 OpenAI 或兼容接口的模型服务。
- 设置访问密码，避免服务被他人使用。
- 支持自定义模型列表与 WebDAV 白名单。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-chatgpt-next-web` |
| 目标平台 | x86 |
| 额外依赖 | 无（模型服务由用户在向导中填写） |

## 安装与使用

安装时设置 Web 访问端口并填写 API Key；访问密码建议改成自己的密码，避免服务被他人使用。安装后从应用中心打开即可对话。
