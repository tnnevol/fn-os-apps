# Opengist

## 应用简介

Opengist 是自托管的代码片段分享服务，后端使用 Git 存储，支持版本历史。

## 主要能力

- 创建与分享代码片段。
- 基于 Git，保留完整修改历史。
- 支持公开/私有与语法高亮。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-opengist` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开并注册账号。片段仓库与数据库保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
