# Kodbox

## 应用简介

可道云 Kodbox 是可私有化部署的在线文件管理与协作平台，提供网盘式文件浏览与分享。

## 主要能力

- 网页端文件管理与上传下载。
- 多用户与权限控制。
- 在线预览、分享链接与协作。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-kodbox` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开并完成初始化向导。站点文件与用户数据保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复；**请预留足够存储空间**。
