# Artalk

## 应用简介

Artalk 是简洁的自托管评论系统，可作为静态博客或任意网站的评论后端。

## 主要能力

- 为静态站点提供评论后端。
- 支持多站点、表情与邮件通知。
- 提供管理后台进行评论审核。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-artalk` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，并填写默认站点名称与地址；评论界面语言与容器时区也可在此配置。安装完成后从应用中心打开管理后台，把评论组件嵌入到自己的网站中即可使用。评论数据保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
