# ntfy

## 应用简介

ntfy 是通过 HTTP 推送通知的自托管服务，支持手机与桌面客户端订阅。

## 主要能力

- 通过 HTTP 接口发布通知。
- 手机与桌面客户端订阅接收。
- 支持访问控制与消息缓存。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-ntfy` |
| 目标平台 | x86 |
| 额外依赖 | 无（客户端由用户自行安装） |

## 安装与使用

安装时设置 Web 访问端口与容器时区；「容器内监听端口」为高级项，**保持默认值即可**。安装完成后从应用中心打开即可测试发布通知。

推送缓存与配置分别保存在应用数据目录的 `cache/ntfy`、`ntfy` 子目录中。数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。

## 高级配置

### 运行用户

上游把 `PUID`/`PGID` 做成向导字段（默认 `1000`），并以 `user: ${PUID}:${PGID}` 运行容器。fnOS 上包用户的 UID 是**动态分配**的，固定填 `1000` 通常会指向登录用户而非本应用的包用户，导致数据目录权限错误。本应用因此**移除了这两个向导字段**，改为固定以本应用的包用户运行（`user: "${TRIM_UID}:${TRIM_GID}"`）。

### 容器内监听端口

上游还有 `APP_PORT_INTERNAL` 字段（容器内监听端口，默认 80），本应用保留为向导字段并保留上游的 `healthcheck`。除非明确知道需要修改，否则保持默认值。
