# n8n

## 应用简介

n8n 是工作流自动化平台，通过可视化节点把各类服务连接起来，并原生支持接入大模型。

## 主要能力

- 可视化节点编排，连接数百种服务与应用。
- 原生 AI 能力，可在流程中调用大模型。
- 支持定时触发、Webhook 与手动执行。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-n8n` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口与容器时区，安装完成后从应用中心打开并创建管理员账号。工作流与凭据保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
