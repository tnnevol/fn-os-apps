# Halo

## 应用简介

Halo 是简洁高效的开源建站系统，可用于搭建博客、知识库和企业官网。

## 主要能力

- 支持博客和内容发布。
- 支持知识库和企业站点场景。
- 提供可扩展的主题与插件生态。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-halo` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装完成后从 fnOS 桌面入口进入初始化页面，按向导完成管理员账号、站点地址和主题配置。
