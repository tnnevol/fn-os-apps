# BettaFish（微舆）

## 应用简介

BettaFish（微舆）是多 Agent 舆情分析助手，从公开信息中还原舆情走向。

## 主要能力

- 多 Agent 协同的舆情分析。
- 查询、媒体、洞察三类分析引擎。
- 自动生成分析报告。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-bettafish` |
| 目标平台 | x86 |
| 外部依赖 | **外部 PostgreSQL / MySQL 数据库** |

## 安装与使用

安装时设置 Web 访问端口与三个分析引擎端口，填写数据库连接信息（地址、端口、库名、用户名、密码分开填写）。

**数据库需用户自备**：安装时填写数据库连接信息。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**四个入口**：主界面与查询、媒体、洞察三个引擎界面各有一个桌面入口。

**已修正的上游缺陷**：上游挂载了一个 `.env` 文件，但该镜像**实际不消费 `.env` 中的配置**（所有配置均通过环境变量传入，且上游仓库并不提供该文件），因此转换为不挂载。
