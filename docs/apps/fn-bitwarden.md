# Bitwarden

## 应用简介

Bitwarden 是开源密码管理器，用于安全保存网站登录信息、信用卡和安全笔记等敏感数据。

## 主要能力

- 集中管理密码和登录凭据。
- 保存信用卡、安全笔记等敏感信息。
- 通过自托管方式将数据运行在自己的 NAS 上。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-bitwarden` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

密码管理器涉及敏感数据。安装后请优先完成管理员账号、安全策略和备份配置，再将客户端连接到 NAS 上的服务地址。
