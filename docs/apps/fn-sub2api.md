# Sub2API

## 应用简介

Sub2API 把多个上游 API 订阅聚合为统一接口，并提供用量与配额管理。

## 主要能力

- 多上游 API 聚合为统一入口。
- 用量统计与配额限制。
- 管理员后台与令牌管理。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-sub2api` |
| 目标平台 | x86 |
| 外部依赖 | **外部 PostgreSQL + Redis** |

## 安装与使用

安装时设置 Web 访问端口与容器时区，填写数据库连接信息（地址、端口、库名、用户名、密码分开填写）、**Redis 地址/密码**、**管理员邮箱/密码**与**两个密钥**。

**数据库需用户自备**：安装时填写数据库连接信息。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**两个密钥**（JWT 密钥、二次验证加密密钥）与管理员密码上游均为弱占位或空值，已改为必填；**留空可能导致无法登录**。

**关于数据库类型**：上游声明了该字段但容器并未使用（属上游冗余），因此本应用不提供该选项。

**服务模式与运行模式**：一般保持默认（release / standard）即可。数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。
