# draw.io

## 应用简介

draw.io 是开源的在线图表工具，用于绘制流程图、架构图与思维导图。

## 主要能力

- 流程图、架构图与思维导图。
- 无需登录即可使用。
- 支持导出多种图片与矢量格式。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-drawio` |
| 目标平台 | x86 |
| 外部依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口与 HTTPS 端口，安装完成后从应用中心打开即可使用。

**本应用是无状态的**：图表保存在浏览器本地或你指定的存储位置，容器不保存用户数据，因此卸载时无需保留数据。**HTTPS 端口需要证书才能使用**（证书自备）。
