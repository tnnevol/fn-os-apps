# ComfyUI

## 应用简介

ComfyUI 是模块化的 AI 图像创作引擎，通过节点图组合模型与处理步骤。

## 主要能力

- 节点图方式搭建图像生成流程。
- 支持多种模型与自定义节点扩展。
- 可保存与复用工作流。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-comfyui` |
| 目标平台 | x86 |
| 额外依赖 | 无（模型文件由用户在界面中下载或导入） |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开，导入模型并搭建节点图即可开始创作。模型、工作流与生成结果保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复；**模型文件较大，请注意存储容量**。

本应用申请了较大的共享内存（8GB）与更高的资源上限，以便运行图像生成任务，请确认目标 NAS 有足够内存。
