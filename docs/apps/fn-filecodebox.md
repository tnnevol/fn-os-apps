# FileCodeBox

## 应用简介

FileCodeBox 是轻量的自托管文件分享工具，用取件码收发文件。

## 主要能力

- 生成取件码分享文件，无需注册。
- 支持设置过期时间与取件次数。
- 提供管理后台查看与清理文件。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-filecodebox` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开，上传文件后把取件码发给对方即可。上传的文件与配置保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复；**分享的文件会占用存储空间**。
