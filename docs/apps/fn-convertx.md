# ConvertX

## 应用简介

ConvertX 是自托管的在线文件转换器，支持文档、图片、音视频等多种格式互转。

## 主要能力

- 支持多种文档与媒体格式互转。
- Web 界面直接上传转换，无需客户端。
- 可注册账号以保存转换记录。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-convertx` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开并上传文件进行转换。转换任务与临时文件保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
