# 1Panel AI 门户

## 应用简介

1Panel AI 门户为企业用户提供自助式的 API Key 管理、技能市场和 MCP 市场能力。

## 主要能力

- 自助式 API Key 申请与管理。
- 技能市场与 MCP 市场浏览。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-ai-portal` |
| 目标平台 | x86 |
| 额外依赖 | **需要外部 1Panel 企业版实例** |

## 安装与使用

安装时设置 Web 访问端口，并填写已有的 1Panel 企业版实例地址与其 API Key。**本应用依赖外部 1Panel 企业版实例，不是独立部署的完整产品**——没有可用的 1Panel 实例时，应用可以启动但功能不可用。安装完成后从应用中心打开。
