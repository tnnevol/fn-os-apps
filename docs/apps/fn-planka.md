# Planka

## 应用简介

Planka 是看板式项目管理工具，支持实时协作与卡片流转。

## 主要能力

- 看板、列表与卡片管理。
- 实时协作与成员指派。
- 附件、标签与截止日期。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-planka` |
| 目标平台 | x86 |
| 外部依赖 | **外部 PostgreSQL** |

## 安装与使用

安装时设置 Web 访问端口，填写**站点访问地址**、**会话密钥**、**初始管理员信息**与数据库连接信息。

**数据库需用户自备**：安装时填写数据库连接信息。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**会话密钥与管理员密码**上游默认值都是弱占位符，已改为必填；**站点访问地址**上游默认 `localhost`，在容器语义下无意义，已改为必填。数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。
