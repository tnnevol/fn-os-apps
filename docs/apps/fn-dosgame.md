# 中文 DOS 游戏

## 应用简介

中文 DOS 游戏合集，把经典 DOS 游戏搬到浏览器中，打开即玩。

## 主要能力

- 收录多款经典中文 DOS 游戏。
- 浏览器内直接运行，无需额外安装。
- 支持键盘与存档操作。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-dosgame` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开，在列表中点击游戏即可游玩。游戏库保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
