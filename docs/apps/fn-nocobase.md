# NocoBase

## 应用简介

NocoBase 是面向开发者的无代码平台，用插件与数据模型快速搭建业务系统。

## 主要能力

- 数据模型驱动的无代码搭建。
- 插件体系与自定义扩展。
- 细粒度权限与工作流。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-nocobase` |
| 目标平台 | x86 |
| 外部依赖 | **外部 MySQL / MariaDB / PostgreSQL** |

## 安装与使用

安装时设置 Web 访问端口与容器时区，填写数据库连接信息（地址、端口、库名、用户名、密码分开填写）与**应用密钥**。

**数据库需用户自备**：安装时填写数据库连接信息。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**应用密钥**用于加密敏感数据，上游默认值是弱占位符，已改为必填；**安装后不要更改**，否则已保存的数据将无法解密。数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。
