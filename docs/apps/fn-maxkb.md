# MaxKB

## 应用简介

MaxKB 是面向企业的智能体平台，支持把文档导入为知识库并基于大模型提供问答能力。

## 主要能力

- 文档导入与知识库管理（支持多种文件格式）。
- 基于知识库的问答，可对接多种大模型。
- 支持编排工作流与对外提供 API。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-maxkb` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开，按向导创建知识库并导入文档。知识库与配置数据保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
