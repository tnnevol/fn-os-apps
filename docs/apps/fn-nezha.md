# Nezha

## 应用简介

哪吒监控是轻量的服务器监控与探针管理面板，支持多主机状态与告警通知。

## 主要能力

- 集中监控多台服务器的资源与在线状态。
- 支持多种告警通知渠道。
- 提供探针一键接入。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-nezha` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开并创建管理员账号，再在各被监控主机上部署探针。监控数据保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
