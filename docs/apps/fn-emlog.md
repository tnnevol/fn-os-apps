# Emlog Pro

## 应用简介

Emlog Pro 是轻量的 PHP 博客系统，提供文章、分类与插件管理。

## 主要能力

- 轻量的博客写作与发布。
- 分类、标签与评论。
- 主题与插件扩展。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-emlog` |
| 目标平台 | x86 |
| 外部依赖 | **外部 MySQL / MariaDB** |

## 安装与使用

安装时设置 Web 访问端口，填写**站点访问地址**与数据库连接信息（地址、库名、用户名、密码）。

**数据库需用户自备**：安装时填写数据库连接信息。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**关于数据库端口**：上游编排**只提供了数据库地址、没有端口配置**，且镜像内没有可用的端口配置项，因此本应用**仅支持数据库默认端口（3306）**。若你的数据库使用其它端口，需要自行调整编排文件。**我们没有提供端口字段，以避免出现"填了却不生效"的假选项。**

**站点访问地址**上游默认 `localhost`，在容器语义下无意义，已改为必填。数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。
