# Metabase

## 应用简介

Metabase 是开源 BI 工具，无需 SQL 即可做数据查询与可视化看板。

## 主要能力

- 无需 SQL 的数据查询与图表。
- 可视化看板与定时订阅。
- 多数据源接入与权限管理。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-metabase` |
| 目标平台 | x86 |
| 外部依赖 | **外部 MySQL 数据库** |

## 安装与使用

安装时设置 Web 访问端口，填写数据库连接信息（地址、端口、库名、用户名、密码分开填写）。

**数据库需用户自备**：安装时填写数据库连接信息。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**为什么需要外部数据库**：Metabase 内置的 H2 数据库只适合单机试用，生产使用官方推荐外部数据库；上游也明确设计为使用外部 MySQL 保存应用数据。**注意本应用的元数据库是 MySQL**（与它分析的业务数据源无关）。

**已修正的上游缺陷**：上游把数据库端口写死为 `3306`，会把你锁死在默认端口；转换为向导字段后可自行填写。
