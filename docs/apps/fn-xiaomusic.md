# xiaomusic

## 应用简介

xiaomusic 把小米音箱接入音乐服务，用语音或网页控制播放。

## 主要能力

- 让小米音箱播放自建音乐库。
- 语音指令与网页控制。
- 支持多种音乐源。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-xiaomusic` |
| 目标平台 | x86 |
| 外部依赖 | 无 |
| 用户数据 | 共享目录（文件管理器中可见） |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开并按提示完成配置。

**共享目录**：把音乐文件放入共享目录下的 `music` 子目录（在文件管理器中位于 `<存储卷>/@appshare/fn-<应用名>/music`）。

应用自身的配置/索引数据保存在应用私有数据目录（文件管理器中不可见），与你的媒体文件分开存放。（配置保存在应用数据目录的 `data/conf`。）

**已修正的上游缺陷**：上游端口写法为 `${HOST_IP}:${端口}:8090`，但 `HOST_IP` 在飞牛 fnOS 侧没有来源，会展开为空值。转换为直接绑定所有网卡（与空值展开的行为一致，但为显式表达）。

## 共享目录结构

| 用途 | 共享目录下的子目录 | 容器内路径 |
| --- | --- | --- |
| 音乐库 | `music` | `/app/music` |

> **关于共享目录路径（如实说明，尚未真机验证）**
>
> 本应用的共享目录通过 `${TRIM_APPDEST_VOL}/@appshare/fn-<应用名>/` 挂载。其中 `TRIM_APPDEST_VOL` 是飞牛 fnOS 提供的「应用安装所在的存储空间路径」变量，**但它在 compose 中的展开尚未经过真机验证**。
>
> - 若展开正常：共享目录位于你安装应用时选择的存储卷，例如安装在存储 4 时为 `/vol4/@appshare/fn-<应用名>/`。
> - 若该变量为空：路径会退化为 `/@appshare/...`，**容器仍能正常启动、应用也能运行，但数据会落到错误位置**（这是静默错误，不会报错）。
>
> 安装后可用以下命令自查（在目标 NAS 上执行）：
>
> ```bash
> docker inspect <容器名> --format '{{json .Mounts}}'
> ```
>
> 查看 `Source` 是真实路径还是 `/@appshare/...`。
