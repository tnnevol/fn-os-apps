# Music Tag Web

## 应用简介

Music Tag Web 是音乐标签编辑器，批量整理音频元数据与封面。

## 主要能力

- 在线编辑音频标签（ID3 等）。
- 批量修改与封面管理。
- 按标签整理与重命名文件。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-music-tag-web` |
| 目标平台 | x86 |
| 外部依赖 | 无 |
| 用户数据 | 共享目录（文件管理器中可见） |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开并登录使用。

**共享目录**：把要整理的音频文件放入共享目录下的 `media` 子目录（在文件管理器中位于 `<存储卷>/@appshare/fn-<应用名>/media`）。**该目录以读写方式挂载——本应用会把编辑后的标签写回音频文件本身。** 首次使用前建议先备份原始文件。

应用自身的配置/索引数据保存在应用私有数据目录（文件管理器中不可见），与你的媒体文件分开存放。（应用数据库在应用数据目录的 `data`。）

## 共享目录结构

| 用途 | 共享目录下的子目录 | 容器内路径 | 挂载方式 |
| --- | --- | --- | --- |
| 音乐文件 | `media` | `/app/media` | 读写 |

> **⚠️ 数据安全提示**：本应用的设计用途就是**修改音频文件的标签**（写入文件本身，而不仅是数据库）。请在首次操作前**备份你的音乐文件**，或先在少量文件上试用。

> **关于共享目录路径（如实说明，尚未真机验证）**
>
> 本应用的共享目录通过 `${TRIM_APPDEST_VOL}/@appshare/fn-<应用名>/` 挂载。其中 `TRIM_APPDEST_VOL` 是飞牛 fnOS 提供的「应用安装所在的存储空间路径」变量，**但它在 compose 中的展开尚未经过真机验证**。
>
> - 若展开正常：共享目录位于你安装应用时选择的存储卷，例如安装在存储 4 时为 `/vol4/@appshare/fn-<应用名>/`。
> - 若该变量为空：路径会退化为 `/@appshare/...`，**容器仍能正常启动、应用也能运行，但数据会落到错误位置**（这是静默错误，不会报错）。
>
> 安装后可用以下命令自查（在目标 NAS 上执行）：
>
> ```bash
> docker inspect <容器名> --format '{{json .Mounts}}'
> ```
>
> 查看 `Source` 是真实路径还是 `/@appshare/...`。
