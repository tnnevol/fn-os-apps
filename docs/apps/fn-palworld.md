# Palworld Server

## 应用简介

幻兽帕鲁（Palworld）专用游戏服务器，提供联机游玩、RCON 远程管理与 REST 接口。

## 主要能力

- 多人联机游玩，最多支持自定义人数上限。
- RCON 远程管理，可脚本化控制。
- REST API 供外部系统集成。
- 可选公开社区联机。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-palworld` |
| 目标平台 | x86 |
| 外部依赖 | 无 |

::: warning 本应用没有网页界面
安装后**不会出现在桌面**，也没有 Web 控制台——它是游戏服务器。
需要用**游戏客户端**（游戏端口）或 **RCON 工具**（RCON 端口）连接，或调用 REST 接口。
:::

## 安装与使用

安装分三步：游戏端口 → 管理与接口 → 服务器设置。

### 关键端口

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `GAME_PORT` | 8211 | 玩家连接端口（UDP） |
| `QUERY_PORT` | 27015 | Steam 查询端口，容器内固定 27015 |
| `RCON_PORT` | 25575 | 远程管理端口 |
| `REST_PORT` | 8212 | REST API 端口 |

### 开始使用

1. 安装完成后，在应用中心确认应用状态为**运行中**
2. 首次启动会自动下载游戏服务端，**耗时较长**，请耐心等待并观察应用日志
3. 下载完成后，玩家用游戏客户端连接 `PUBLIC_IP` 与 `GAME_PORT` 即可进入

## 高级配置

### 关于查询端口

上游编排写的是 `${QUERY_PORT}:${QUERY_PORT}`，两侧用同一个变量——**用户一改就会连失联**，因为游戏客户端的查询端口是**硬编码的 27015**。本应用改为**固定容器侧 27015、只让用户改宿主侧**，避免这个问题。

### 修改服务端配置

游戏服务端的配置文件位于应用数据目录的 `palworld/` 子目录。安装向导中的「保留自定义配置」选项开启后，启动时不会用向导里的设置覆盖已有配置文件，便于手工调参。

数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复存档。

### 端口冲突

`27015`（查询）与 `25575`（RCON）是游戏生态的约定端口。若 NAS 上已有服务占用，可在安装时改用其他宿主端口——客户端需要相应配置对应的映射。
