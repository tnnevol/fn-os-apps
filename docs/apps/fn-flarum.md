# Flarum

## 应用简介

Flarum 是简洁现代的论坛程序，主打快速与移动端体验。

## 主要能力

- 轻快简洁的论坛体验。
- 移动端优先的界面。
- 扩展机制与主题体系。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-flarum` |
| 目标平台 | x86 |
| 外部依赖 | **外部 MySQL 数据库** |

## 安装与使用

安装时设置 Web 访问端口与容器时区，填写**论坛访问地址**（如 http://192.168.1.10:40020，**填错会导致静态资源与登录跳转异常**）、数据表前缀，以及数据库连接信息。

**数据库需用户自备**：安装时填写数据库连接信息。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**权限说明**：上游以硬编码的 `PUID`/`PGID=1000` 运行。fnOS 上包用户的 UID 是动态分配的，固定 1000 会指向登录用户而非本应用包用户，故改为由 `TRIM_UID`/`TRIM_GID` 注入。

数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。
