# MoviePilot

## 应用简介

MoviePilot 是影视自动化管理工具，用于媒体库管理、订阅、下载和整理流程。

## 主要能力

- 管理影视媒体库。
- 创建和管理自动化订阅。
- 执行媒体下载与整理任务。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-moviepilot` |
| 目标平台 | x86 |
| 依赖 | Python 3.12、Node.js 20 |

## 安装与使用

安装前确认依赖运行时已满足。首次启动后完成媒体目录、下载器、索引器和通知渠道配置；不同媒体服务的访问权限需单独检查。
