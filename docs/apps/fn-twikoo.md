# Twikoo

## 应用简介

Twikoo 是简洁安全的静态网站评论系统，数据可完全自托管。

## 主要能力

- 为静态站点提供评论后端。
- 数据自托管，支持多种存储方式。
- 支持评论管理与邮件通知。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-twikoo` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开进入管理面板，再在前端页面引入评论组件。评论数据保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
