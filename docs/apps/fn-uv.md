# uv

## 应用简介

uv 是由 Astral 开发的高性能 Python 包和项目管理工具，用于替代传统的 pip 与 pip-tools 工作流。

## 主要能力

- 管理 Python 包和项目依赖。
- 创建和管理虚拟环境。
- 提供快速的依赖解析能力。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-uv` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装后通过 fnOS 应用提供的命令行入口使用 `uv`。在脚本中调用时，请确认应用命令目录已加入当前用户的 `PATH`。
