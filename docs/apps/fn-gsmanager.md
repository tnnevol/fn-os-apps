# GSManager

## 应用简介

GSManager 是游戏服务端管理面板，可视化管理 Steam 等游戏服务器。

## 主要能力

- 图形化创建与管理游戏服务端实例。
- 启动、停止与查看服务端控制台。
- 文件管理与备份。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-gsmanager` |
| 目标平台 | x86 |
| 外部依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口、游戏服务端口与时区，安装完成后从应用中心打开，**默认账户为 `admin` / `admin123`，请立即修改密码**。

**游戏服务端口**是非网页端口（游戏客户端连接的端口），**没有桌面入口**。

数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。

**运行身份**：上游显式要求以 root（`user: root`）运行。依据镜像内的实际权限（`/root` 为 `0775`、启动脚本为 `0755`，作者有意支持非 root），转换后改为以 fnOS 为应用分配的用户运行。

> **真机验证项**：游戏服务端与 SteamCMD 在非 root 用户下的实际运行情况尚未在真机确认。若出现权限相关报错，请在应用页面反馈。

## 端口说明

| 端口 | 用途 | 桌面入口 |
| --- | --- | --- |
| Web 访问端口（默认 3001） | 管理面板界面 | ✅ 有 |
| 游戏服务端口（默认 27015） | 游戏客户端连接 | — 无 |

## 安全提示

面板的默认账户是 `admin` / `admin123`。**首次登录后请立即修改密码**——该面板可管理服务器上的游戏实例与文件。
