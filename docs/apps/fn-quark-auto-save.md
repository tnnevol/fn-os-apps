# 夸克转存

## 应用简介

夸克转存用于自动化处理夸克网盘任务，适合在 NAS 上执行签到、转存和媒体库整理流程。

## 主要能力

- 夸克网盘签到。
- 自动转存和命名整理。
- 推送提醒和刷新媒体库。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-quark-auto-save` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装后按照应用向导填写账号或 Cookie 等配置，并根据任务需求设置转存规则和推送方式。敏感配置请勿提交到仓库或公开日志。
