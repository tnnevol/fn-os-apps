# Waline

## 应用简介

Waline 是带后端的评论系统，可作为静态博客的评论服务，支持多站点与多种存储。

## 主要能力

- 为静态站点提供评论后端。
- 支持评论审核与通知。
- 内置 SQLite 存储，也可对接外部数据库。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-waline` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口与容器时区，并填写 **JWT 密钥**（上游默认值是弱占位符，请自行设置一个唯一值）；站点名称、地址、管理员邮箱与安全域名均为可选项。安装完成后从应用中心打开管理后台，再把评论组件嵌入自己的网站。评论数据保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
