# Excalidraw

## 应用简介

Excalidraw 是手绘风格的在线白板，用于画流程图、架构图与草图。

## 主要能力

- 手绘风格的白板与草图。
- 流程图、架构图与线框设计。
- 支持导出 PNG / SVG。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-excalidraw` |
| 目标平台 | x86 |
| 外部依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开即可使用。

**本应用是无状态的**：画布数据保存在浏览器本地（或用其协作/存储服务），容器不保存用户数据，卸载时无需保留数据。

**运行身份**：本应用以目标 NAS 的包用户（非 root）运行。
