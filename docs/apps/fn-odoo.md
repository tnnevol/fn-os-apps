# Odoo

## 应用简介

Odoo 是开源 ERP，覆盖销售、库存、财务、人事等企业管理模块。

## 主要能力

- 销售、采购与库存管理。
- 财务记账与发票。
- 项目、工时与人事模块。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-odoo` |
| 目标平台 | x86 |
| 外部依赖 | **外部 PostgreSQL** |

## 安装与使用

安装时设置 Web 访问端口，填写数据库连接信息（地址、端口、库名、用户名、密码分开填写）。

**数据库需用户自备**：安装时填写数据库连接信息。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**已修正的上游缺陷**：

- 上游未提供数据库端口配置（隐含 5432），已补出端口字段，避免把你锁死在默认端口。
- 上游未挂载配置目录，导致 `odoo.conf` 落在容器内、**容器重建即丢失配置**；已补出 `/etc/odoo` 挂载（对应应用数据目录的 `data/etc`）。

数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。

## 高级配置

### 第三方模块

`data/addons`（容器内 `/mnt/extra-addons`）用于放置自定义或第三方模块。把模块目录放入该子目录后重启应用，即可在「应用」页面安装。
