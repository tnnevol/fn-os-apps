# Answer

## 应用简介

Answer 是适用于任何规模团队的问答平台，支持提问、回答、投票与内容协作。

## 主要能力

- 提问、回答与采纳最佳答案。
- 标签分类、搜索与内容审核。
- 用户与权限管理。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-answer` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开并完成初始化设置。问答数据与上传附件保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
