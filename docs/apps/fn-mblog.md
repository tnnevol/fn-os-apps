# MBlog

## 应用简介

MBlog 是简洁的个人博客系统，支持 Markdown 写作、标签分类与评论。

## 主要能力

- Markdown 写作与实时预览。
- 标签、归档与全文搜索。
- 数据自持，内置 SQLite 存储。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-mblog` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开并创建管理员账号。博客内容与数据库保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
