# JSON Hero

## 应用简介

JSON Hero 是 JSON 可视化浏览工具，提供树形、列与编辑器多种视图。

## 主要能力

- JSON 树形/列/编辑器多视图。
- 大文件快速预览与搜索。
- 通过 URL 分享查看。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-jsonhero` |
| 目标平台 | x86 |
| 外部依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开。

**本应用是无状态的**：不上传、不保存你的数据到容器，卸载时无需保留数据。

**运行身份**：本应用以目标 NAS 的包用户（非 root）运行。
