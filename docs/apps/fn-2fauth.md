# 2FAuth

## 应用简介

2FAuth 是自托管的双因素验证码管理工具，集中保存 TOTP 账户并生成安全代码。

## 主要能力

- 集中管理多个站点的 TOTP 双因素账户。
- 生成动态验证码，支持分组与搜索。
- 数据保存在自有 NAS 上，不依赖第三方服务。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-2fauth` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，并填写外部访问地址与 **32 位加密密钥**（`APP_KEY`）。加密密钥用于加密已保存的 2FA 数据，**安装后不要更改**，否则原有数据将无法解密。安装完成后从应用中心打开，注册账号即可开始使用。

本应用涉及账号安全，请做好数据备份：数据库保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
