# MySQL v8

## 应用简介

MySQL v8 应用提供 MySQL 8.4.9 原生服务，适合为 fnOS 上的其他应用提供关系型数据库。

## 主要能力

- 提供 MySQL 8.4.9 数据库服务。
- 使用 fnOS Native 方式运行，不依赖 Docker 容器。
- 支持数据库服务的本地和远程访问配置。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-mysql_v8` |
| 目标平台 | x86_64 |
| 额外依赖 | 无 |

## 安装与使用

安装后根据向导配置数据库端口、初始化账号和访问方式。生产使用前请设置强密码，并定期备份数据库目录。
