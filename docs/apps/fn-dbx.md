# DBX

## 应用简介

DBX 是轻量的数据库管理工具，通过浏览器连接并管理数据库。

## 主要能力

- 浏览器中管理多种数据库。
- 无需在本地安装客户端。
- 轻量、启动快。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-dbx` |
| 目标平台 | x86 |
| 外部依赖 | 无（被管理的数据库由用户自行提供） |

## 安装与使用

安装时设置 Web 访问端口，并填写**访问密码**（上游默认值是弱占位符，请自行填写）。安装完成后从应用中心打开，再在界面中填入要连接的数据库信息。

**说明**：上游把该密码归在数据库命名空间下，但它只是**本应用自身的访问密码**，不是数据库凭据，因此向导中命名为「访问密码」。

数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。
