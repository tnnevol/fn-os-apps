# IT-Tools

## 应用简介

IT-Tools 是面向开发者的在线工具集合，把日常开发中零散使用的实用小工具集中在一个自托管界面里。

## 主要能力

- 加密类工具：Token 生成、文本哈希、UUID 生成、加解密。
- 转换类工具：YAML、JSON、Base64 等格式互转。
- Web 与网络类工具：URL 编解码、User-Agent 解析、网址解析。
- 开发类工具：Docker run 转 Compose、Cron 表达式生成、SQL 格式化。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-it-tools` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开即可使用。应用无状态，不保存用户数据，卸载时无需担心数据丢失。
