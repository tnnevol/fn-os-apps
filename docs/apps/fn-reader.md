# 阅读

## 应用简介

阅读是一个在线电子书阅读器，封装为 fnOS 应用后可直接在 NAS 上运行和访问。

## 主要能力

- 支持多种电子书格式。
- 提供书架管理和阅读进度同步。
- 支持全文搜索和阅读主题定制。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-reader` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

从 Release 下载 `.fpk` 后，在 fnOS 应用中心手动安装。安装完成后从桌面入口打开应用；开发调试可使用 `appcenter-cli install-local`。
