# Vane

## 应用简介

Vane 是自托管的 AI 搜索引擎，聚合多种来源并给出带引用的答案。

## 主要能力

- 聚合多个搜索来源并生成答案。
- 提供引用来源便于核对。
- 对话式追问与上下文保持。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-vane` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开开始提问。搜索历史与配置保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
