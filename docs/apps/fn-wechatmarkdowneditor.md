# WeChat Markdown Editor

## 应用简介

WeChat Markdown Editor（doocs/md）是面向公众号排版的 Markdown 编辑器，边写边预览并一键复制排版好的内容。

## 主要能力

- Markdown 实时预览与公众号样式排版。
- 支持代码高亮、表格、公式与自定义主题。
- 一键复制渲染结果，直接粘贴到公众号后台。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-wechatmarkdowneditor` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开即可开始编辑。文档在浏览器本地处理。
