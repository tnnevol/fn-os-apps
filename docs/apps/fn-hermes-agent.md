# Hermes Agent

## 应用简介

Hermes Agent 是 Nous Research 开发的 AI 代理，支持多平台消息网关、自主学习、技能创建和跨会话记忆。

## 主要能力

- 支持 Telegram、Discord、Slack 等消息平台。
- 支持技能创建和持续改进。
- 提供跨会话记忆、计划自动化和多工具协作能力。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-hermes-agent` |
| 目标平台 | x86 |
| 依赖 | Python 3.11、fn-nvm、fn-uv |

## 安装与使用

安装时按照向导完成运行时和模型相关配置。首次使用前应配置消息平台凭据，并限制应用数据目录和凭据文件的访问权限。
