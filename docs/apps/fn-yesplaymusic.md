# YesPlayMusic

## 应用简介

YesPlayMusic 是第三方网易云音乐播放器，界面简洁，支持登录、歌单与歌词显示。

## 主要能力

- 登录网易云账号并同步歌单与收藏。
- 歌词显示与多种播放模式。
- 支持浅色与深色主题。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-yesplaymusic` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开，登录自己的网易云账号即可使用。第三方客户端，账号使用风险请自行评估。
