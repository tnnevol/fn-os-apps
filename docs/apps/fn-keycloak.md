# Keycloak

## 应用简介

Keycloak 是开源的身份与访问管理平台，提供单点登录与权限管理。

## 主要能力

- OIDC / SAML 单点登录。
- 用户联邦与角色权限。
- 管理控制台与细粒度授权。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-keycloak` |
| 目标平台 | x86 |
| 外部依赖 | **外部 MariaDB / MySQL / PostgreSQL 数据库** |

## 安装与使用

安装时设置 Web 访问端口，填写**站点访问地址**、**初始管理员密码**，以及数据库连接信息（地址、端口、库名、用户名、密码分开填写）。

**站点访问地址很关键**：该值用于生成 token 的 issuer 与前端跳转地址；**填错会导致登录页反复跳转、token 校验失败**。请填目标 NAS 的可访问地址（含协议与端口，如 `http://192.168.1.10:8080`）；**未配置反向代理时不要填域名**。

**初始管理员密码**仅在首次启动、尚无管理员时生效。上游默认值是固定弱占位符，请自行设置。

**数据库需用户自备**：安装时填写数据库连接信息。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**数据库类型**沿用上游的三个选项（MariaDB / MySQL / PostgreSQL），未额外开放开发用与冷门数据库类型。

## 高级配置

### 反向代理

本应用开启了 `KC_PROXY_HEADERS=xforwarded`，以便在反向代理后正确识别客户端协议与地址。若你在前置反向代理上终结 TLS，请同时在应用内配置相应的 hostname 策略，避免 issuer 与实际访问地址不一致。
