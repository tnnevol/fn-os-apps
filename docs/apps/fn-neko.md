# Neko

## 应用简介

Neko 是自托管的虚拟浏览器，在容器里运行浏览器并通过 WebRTC 远程使用。

## 主要能力

- 在浏览器中远程操作容器内的浏览器。
- 多人同时观看与协同操作。
- 支持 Firefox、Chromium、KDE 等多种镜像。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-neko` |
| 目标平台 | x86 |
| 外部依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口、**普通用户与管理员的登录密码**、屏幕分辨率、对外 IP 等，安装完成后从应用中心打开并登录。

**密码必须修改**：上游默认值是弱占位符（`neko` / `admin`），转换后已改为**留空并必填**。**请设置强口令**——任何能访问该端口的人都能操作容器内的浏览器。

**对外 IP 必须按实际填写**：默认值 `127.0.0.1` 只适合「本机浏览器访问本机容器」的测试场景。**从局域网其他设备访问时，请填写 NAS 的实际 IP**，否则 WebRTC 可能连不上。

数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。

**运行身份**：本镜像以 root 启动进程管理器（supervisord），再由其把各项服务降权到容器内的专用用户。**这类镜像的初始化强依赖 root**，因此未覆写运行用户。**注意**：容器内该用户的固定 ID 与 fnOS 为应用分配的用户 ID 不同，属已登记的待验证项。

> **关于浏览器镜像选项**：上游提供 17 个选项，其中 4 个（`vncviewer` 与三个 `arm-` 变体）**实际不存在于镜像仓库，或仅适用于 ARM 架构**，选中会导致镜像拉取失败。本转换**只保留 13 个确实可用的选项**。

## 端口说明

| 端口 | 用途 | 桌面入口 |
| --- | --- | --- |
| Web 访问端口（默认 40277） | 网页界面 | ✅ 有 |
| WebRTC 端口范围（默认 52000-52100，UDP） | 音视频流传输 | — 无 |

**WebRTC 端口范围是 UDP 端口**，用于浏览器与容器之间的音视频传输，不提供网页界面，因此没有桌面入口。若在路由器后使用，可能需要在路由器上放通该 UDP 端口范围。

## 主要配置说明

| 配置 | 说明 |
| --- | --- |
| 屏幕分辨率与帧率 | 虚拟屏幕规格，如 `1920x1080@30`。分辨率越高占用越大 |
| 共享内存大小 | 浏览器对共享内存需求较大，画面卡顿可调大 |
| ICELite 模式 | 适合容器只暴露 UDP 端口的场景，默认启用 |
| 视频/音频编码与码率 | 影响带宽占用与流畅度 |
| 文件传输 | 启用后可在界面上传下载文件，目录为应用数据目录的 `data/downloads` |
