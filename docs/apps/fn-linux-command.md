# Linux Command

## 应用简介

Linux Command 是 Linux 命令速查工具，把常用命令的手册、参数说明和使用示例整理成可搜索的网页。

## 主要能力

- 收录 580 多个 Linux 命令的手册与详解。
- 支持按命令名和关键字搜索。
- 内置命令用法示例，便于日常速查。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-linux-command` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开即可使用。应用无状态，内容随后续版本更新。
