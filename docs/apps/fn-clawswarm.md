# ClawSwarm

## 应用简介

ClawSwarm 是面向 OpenClaw 的开源群体智能协作编排系统，用于组织多个智能体协同完成任务。

## 主要能力

- 编排多个智能体协同工作。
- 提供 Web 界面进行任务配置与观察。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-clawswarm` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开进行配置。数据保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复。
