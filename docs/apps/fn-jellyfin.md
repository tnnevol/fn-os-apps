# Jellyfin

## 应用简介

Jellyfin 是开源的媒体系统，用于集中管理影音库并通过浏览器、电视和移动端串流播放。

## 主要能力

- 集中管理电影、音乐、照片等媒体库。
- 自动刮削元数据并生成封面。
- 支持多设备串流与转码播放。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-jellyfin` |
| 目标平台 | x86 |
| 额外依赖 | 无 |
| 媒体目录 | **需自行准备**（向导中填写绝对路径） |

## 安装与使用

安装时分两步：

1. **基础配置** —— 设置 Web 访问端口（默认 `8096`）。
2. **媒体目录** —— 填写**媒体库目录**与**缓存目录**的绝对路径。

::: warning 请先准备目录
媒体库与缓存目录**需要你在目标 NAS 上事先创建**。向导无法校验路径是否存在，**填错会导致容器启动失败或媒体库为空**。

在文件管理器里确认这两个目录可读写后再填写，例如：

- 媒体库：`/vol1/1000/media`
- 缓存：`/vol1/1000/jellyfin-cache`
:::

安装完成后，在 Jellyfin 中添加媒体库并指定上述目录即可开始刮削与播放。

## 高级配置

### 数据落盘

| 内容 | 位置 |
| --- | --- |
| 应用配置 | `${TRIM_PKGVAR}/data/config`（容器内 `/config`） |
| 媒体文件 | **你指定的目录**（容器内 `/media/media`） |
| 转码缓存 | **你指定的目录**（容器内 `/cache`） |

只有应用配置落在应用数据目录；**媒体与缓存由你自己管理**，卸载应用不会删除它们。

### 修改目录

安装后可通过应用中心的「配置」修改媒体库与缓存目录，**无需卸载重装**。
