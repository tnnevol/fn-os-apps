# LobeChat

## 应用简介

LobeChat 是现代设计的开源大模型聊天应用，支持接入多家模型服务并可通过插件扩展能力。

## 主要能力

- 支持 OpenAI 及兼容接口的模型服务。
- 会话管理、助手预设与提示词模板。
- 插件与知识库扩展，支持多模型切换。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-lobe-chat` |
| 目标平台 | x86 |
| 额外依赖 | 无（模型服务由用户在向导中填写） |

## 安装与使用

安装时设置 Web 访问端口，并按需填写 OpenAI API Key 与接口地址；留空则只能使用本地模型。安装后从应用中心打开即可开始对话。
