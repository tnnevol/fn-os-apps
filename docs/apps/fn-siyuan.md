# 思源笔记

## 应用简介

思源笔记是本地优先的知识管理工具，支持块级引用、双向链接与大纲编辑。

## 主要能力

- 块级引用与双向链接。
- 大纲与文档树管理。
- 数据以本地文件保存，便于备份与迁移。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-siyuan` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口与容器时区，并设置**访问授权码**（打开笔记时需要输入，请设置强口令）。安装完成后从应用中心打开，输入授权码即可使用。

笔记工作区保存在目标 NAS 的应用数据目录中，卸载时选择「保留数据」可在重装后恢复；**建议定期备份该目录**。容器以本应用的包用户身份运行（通过 `TRIM_UID`/`TRIM_GID` 传入）。
