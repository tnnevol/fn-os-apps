# Sun-Panel

## 应用简介

Sun-Panel 是服务器与 NAS 导航面板，把常用服务整理成美观的首页入口。

## 主要能力

- 自定义导航分组与图标。
- 支持多用户与公开/私有模式。
- 可展示简单的系统状态。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-sun-panel` |
| 目标平台 | x86 |
| 额外依赖 | 无 |

## 安装与使用

安装时设置 Web 访问端口，安装完成后从应用中心打开并按向导创建管理员账号。配置、上传的图标与数据库分别保存在目标 NAS 应用数据目录下的 `conf`、`uploads`、`database` 子目录中，卸载时选择「保留数据」可在重装后恢复。
