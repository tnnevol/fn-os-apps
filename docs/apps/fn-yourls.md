# YOURLS

## 应用简介

YOURLS 是自托管的短链接服务，支持自定义短码与访问统计。

## 主要能力

- 短链接生成与自定义短码。
- 点击统计与访问来源。
- 插件与 API 扩展。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-yourls` |
| 目标平台 | x86 |
| 外部依赖 | **外部 MySQL** |

## 安装与使用

安装时设置 Web 访问端口，填写**站点访问地址**、**管理用户名/密码**、**数据表前缀**，以及数据库连接信息（地址、端口、库名、用户名、密码分开填写）。

**数据库需用户自备**：安装时填写数据库连接信息。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

**管理密码**与**数据库密码**上游默认值都是弱占位符，已改为必填；**站点访问地址**填错会导致生成的短链接无效。数据落在目标 NAS 的应用数据目录（`${TRIM_PKGVAR}`）中，卸载时选择「保留数据」可在重装后恢复。
