# DVWA

## 应用简介

DVWA 是故意的漏洞演练靶场，用于在隔离环境中练习渗透测试。

## 主要能力

- 包含 SQL 注入、XSS、文件包含等常见漏洞模块。
- 可切换安全等级（low → impossible）。
- 适合教学与授权测试演练。

## 运行要求

| 项目 | 值 |
| --- | --- |
| 应用目录 | `apps/fn-dvwa` |
| 目标平台 | x86 |
| 外部依赖 | **外部 MySQL / MariaDB** |

## 安装与使用

安装时设置 Web 访问端口，填写数据库连接信息（地址、端口、库名、用户名、密码分开填写），并选择**默认安全等级**与**界面语言**。

**数据库需用户自备**：安装时填写数据库连接信息。**连接失败时应用会启动但功能不可用（页面报数据库错误）**，请确认地址可达、端口已放行、库名与账号密码正确。

> **安全警告**：**本应用是故意包含漏洞的靶场，不是生产软件。** 请只在**隔离的内网环境**中使用，**不要暴露到公网**——默认安全等级 `low` 会开放全部常见漏洞，任何能访问该端口的人都可以入侵该容器。演练结束后建议停止该应用。

**运行身份**：本应用以目标 NAS 的包用户（非 root）运行。**该应用无数据挂载**：靶场数据保存在你所提供的数据库中。

## 高级配置

### 数据库类型

上游向导声明了数据库类型字段，但容器编排**并未使用它**（属上游冗余配置）。本应用只通过地址/端口/库名/账号/密码连接，因此**不提供数据库类型选项**。

### 仅支持数据库默认端口的小差别

与 `emlog` 不同，本应用的上游编排提供了独立的数据库端口变量，因此向导中**可以**填写非默认端口。
