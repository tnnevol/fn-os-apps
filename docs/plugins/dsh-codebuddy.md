# CodeBuddy

`@tnnevol/dsh-codebuddy` 为 DSH 接入腾讯 CodeBuddy 模型目录，通过浏览器 OAuth 登录，无需 API Key。当前插件版本为 `0.1.2-rc.1.3`，适配 DSH `0.1.2-rc.1`。

## 安装

`fn-deepseek-harness` 会在安装和升级时自动安装 npm `rc` 标签对应的版本。其他 DSH 环境可以执行：

```sh
dsh plugin --profile web add @tnnevol/dsh-codebuddy@rc
dsh --profile web --dump-config
```

安装后重启 Web profile。

## 登录

一切交互都在插件 Web 界面中完成。

打开「设置 → CodeBuddy」，点击「添加账号」。插件会在新标签页打开腾讯 CodeBuddy 授权页面，用户完成登录后插件自动轮询换取令牌并持久化。无需输入任何 API Key，也无需使用任何终端命令。

登录成功后，该账号会出现在「账号管理」折叠面板列表中并成为当前账号。展开任意账号面板可查看昵称、UID、企业等详细信息，并可执行「设为当前」或「删除账号」。

## 多账号管理

插件支持同时保存多个 CodeBuddy 账号：

- **添加账号**：点击「添加账号」，可选填写备注名（≤120 字，用于在列表中区分账号），打开浏览器登录后追加账号并成为当前账号；重复登录同一账号会刷新其凭据（备注名保留）而不是产生重复条目。
- **设为当前**：所有请求（模型调用、额度查询）均使用「当前」账号。切换即时生效，无需重启。
- **账号掉线**：某个账号的登录凭据过期后，其面板标记「已掉线」并只保留「重新登录」操作；若掉线的是当前账号，顶部会提示请求已由其他账号接管，重新登录后自动恢复。
- **删除账号**：删除该账号的本地凭据；删除当前账号时自动切换到列表中剩余的第一个账号，删除最后一个账号即退出登录。
- 凭据文件在首次读取旧版单账号格式时自动迁移为多账号格式，无需手工处理；旧版单账号登录信息会被完整保留为第一个账号。

## 用量展示

用量余量展示在对话输入区右侧，采用与 Codex 插件一致的紧凑圆环样式：

- 悬停显示「已用额度 / 总量」和重置时间；
- 点击展开浮层，按计量窗口列出剩余比例；
- 已用百分比达到告警阈值时圆环变为红色。

用量相关偏好可在「设置 → CodeBuddy」中调整：

- **显示额度余量**：控制对话输入区是否展示用量圆环；
- **自动切换阈值**：余量低于该百分比时尝试切换其他账号；
- **余量告警百分比**：已用百分比达到该值时圆环变红，默认 90%。

管理面板的「Token 统计」使用 ECharts 绘制按日输入/输出堆叠柱状图，支持查看最近 7、30 或 90 天数据，并提供悬浮明细、图例和自适应尺寸。统计数据仍来自本地会话 JSONL，不会上传会话内容。

管理面板还包含「账号」和「额度」菜单：账号页支持签到、切换和自动切换；额度页显示账号额度及有效期。上述功能已完成本地实现，真实 NAS 验收由 FNOS-003 跟踪。

## 模型目录

CodeBuddy 的模型目录来自其非 OpenAI 兼容的 `/v3/config` 端点，包含每个模型的上下文容量、输出上限、工具调用、推理和图片输入能力。企业账号额外合并控制台自定义模型。

模型目录只读展示在 DSH 的模型选择器中，无需在插件面板单独维护。
