# 生命周期脚本

Native 应用通过 `cmd/` 下的脚本与 fnOS 应用生命周期对接。脚本应使用标准输出和标准错误记录过程，不要单独维护日志文件。

| 脚本 | 触发时机 | 常见职责 |
| --- | --- | --- |
| `install_callback` | 安装完成阶段 | 初始化目录、安装运行时依赖、生成配置 |
| `main` | 启动、停止和状态管理 | 启动服务、停止服务、检查进程 |
| `upgrade_callback` | 升级阶段 | 迁移配置、更新依赖、处理兼容性 |
| `uninstall_callback` | 卸载阶段 | 卸载依赖、清理数据或保留数据 |

## 编写原则

- 使用 `set -euo pipefail`，尽早检查必需环境变量。
- 使用绝对路径和明确的应用目录，避免依赖当前工作目录。
- 处理 `TRIM_*` 环境变量为空的情况，并输出可读错误。
- 重要操作失败时返回非零状态，让 fnOS 安装流程感知失败。
- 不在脚本中写入用户密钥或其他敏感信息。

## 数据目录

安装回调阶段可以使用 fnOS 提供的环境变量准备应用目录。应用的实际数据布局应在对应应用文档中说明，并与 `config/resource` 的声明保持一致。
